## 任务二：朗读声音克隆
- **工具**：剪映 App（声音克隆功能）
- **步骤**：录制样本 → 生成克隆音色 → 输入脚本 → 导出音频
- **输出文件**： `my_voice.mp4`
## 克隆过程
一、使用剪映 App 输入脚本

1. 打开剪映 → 点击 “开始创作” → 任意选择一张图片，点击 “添加到项目”。
2. 进入编辑界面后，点击底部菜单的 “音频”。
3. 选择“音色克隆”
   · 在音频菜单中，找到 “音色克隆” 或 “克隆音色”
   · 按提示录制 10~20 秒的语音样本，生成克隆音色。
4. 输入文本
   · 克隆音色生成后，系统会弹出一个文本框，让你输入要朗读的文字。
   · 将任务一生成的整段文本（从 text_gen.md 复制）粘贴进去。
   · 确认无误后，点击 “生成” 或 “开始朗读”。
5. 导出音频
   · 生成后，点击右上角的 “导出” 按钮。
   · 导出成功后，在手机相册音频文件，通过微信保存到电脑，重命名为 my_voice.mp4。

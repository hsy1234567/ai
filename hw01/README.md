# N 皇后问题求解器（AI 协作实践）

## 项目简介
本项目是《人工智能导论》课程作业的一部分，主题为“基于 AI 协作的八皇后问题工程化实践”。  
作业要求利用 AI 工具（如 ChatGPT、GitHub Copilot 等）辅助完成以下任务：
- 构建标准 Python 工程（`src/` 和 `tests/` 目录）；
- 实现 N 皇后问题的回溯算法求解器；
- 编写单元测试验证算法正确性；
- 故意引入一个 Bug，观察并记录 AI 定位与修复的过程。

本项目完整记录了与 AI 的交互过程，展示了如何通过提示词引导 AI 生成代码、调试错误和优化代码结构。

## 实验思路
### 算法原理
采用经典的回溯法解决 N 皇后问题：
- 逐行放置皇后，每行只放一个；
- 通过 `is_safe` 函数检查当前位置是否与已放置的皇后冲突（同一列、同一对角线）；
- 若当前行所有列均无法放置，则回溯到上一行；
- 当放置完最后一行时，记录一个有效解。

### AI 协作过程
1. **初始代码生成**：向 AI 提问获取回溯算法的 Python 实现。
2. **单元测试生成**：要求 AI 基于 `unittest` 框架编写测试用例，覆盖 n=1,2,4,8 等边界情况。
3. **Bug 引入与修复**：在正确代码中故意修改一处逻辑（例如改动对角线判断条件），使测试失败；将错误信息提供给 AI，由 AI 分析原因并给出修复建议；按建议修改后测试通过。
4. **代码重构**（可选）：请求 AI 对代码进行模块化优化，提高可读性。

## 运行测试
在项目根目录（即包含 `hw01` 文件夹的目录）下执行以下命令运行所有测试：
```bash
python -m unittest hw01.tests.test_queens
```

或直接指定测试文件路径：

```bash
python -m unittest hw01/tests/test_queens.py
```

若希望运行单个测试方法（例如 test_n4）：

```bash
python -m unittest hw01.tests.test_queens.TestNQueens.test_n4
```

环境要求

· Python 3.8 及以上（本项目使用 Python 3.14.3 开发与测试）
· 无需安装第三方库（仅使用标准库 unittest）
